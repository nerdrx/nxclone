Your avatar. More possibilities.

01 / CLONES

Dance together.

Steps follow the clone’s own facing direction. Turns happen in place. Start 1 m ahead, facing you, then choose your placement.

02 / TOGGLES

Make it theirs.

Separate clothes, props and supported effects in each clone’s Avatar toggles menu. GoGo Loco stays with your main avatar.

03 / AFTERIMAGES

Leave a trail.

Standalone flat silhouettes with individual colours and a separate toggle. Primary-body masking and proximity fade help keep your view clear.

04 / PLACEMENT

Choose your axes.

Position and rotate in Unity or through in-game dials. Select only the axes you need; Distance and Yaw are the default selections.

05 / POSE

Hold the moment.

World drop, freeze, grabbable posing and sampled recording. Optional limb IK, contact attachment and wearing a clone.

06 / SETUP

Start with a check.

Missing FX and expression assets are created on a scene copy. Menus paginate, presets remember your layout, and original assets stay intact.

VPM install

Install nxclone

Add the nxclone repository in ALCOM or Creator Companion, then add nxclone to your avatar project.

Install nxclone · VCCDownload release ↗
Manual repository URL · ALCOM / VCChttps://nerdrx.github.io/nxclone/index.json

The VCC button needs a registered vcc:// handler. On Linux, paste the URL into your VPM-compatible manager.

Then, in Unity

  1. Open Tools → nxclone.
  2. Select a scene avatar and review the avatar check.
  3. Choose clone options, or select Afterimages only.
  4. Generate a scene copy and test it before upload.

Preview status: Linux SDK preprocessing checked the supplied avatar; native Animator checks cover independent clothing and effect toggles. Offscreen rendering checked flat silhouettes. Live VRChat and Windows editor tests remain open. Updating? Regenerate from your original avatar.
